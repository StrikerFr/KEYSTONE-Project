# KEYSTONE User Roles & Portal Access Specification

KEYSTONE provides dedicated user interfaces and permission scopes for 4 distinct user roles:

| Role | Target Workspace | Primary Responsibilities |
| :--- | :--- | :--- |
| **`ADMIN`** | Operations Dashboard & Settings | Full platform administration, SLA policy configuration, organization management, system audit logs. |
| **`MANAGER`** | Operations & Dispatch Board | Work order creation, technician assignment, scheduling conflict resolution, service request conversions, reports. |
| **`TECHNICIAN`** | Technician Mobile Workspace | Viewing assigned daily jobs, starting/pausing work timers, logging parts used, taking photos, marking work complete. |
| **`CUSTOMER`** | Customer Self-Service Portal | Viewing owned company assets, submitting new service requests, monitoring work order progress, reviewing service history. |
