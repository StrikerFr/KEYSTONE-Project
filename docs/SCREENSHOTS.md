# KEYSTONE Application Screenshots Guide

This document outlines key visual artifacts for portfolio display and documentation.

## Recommended Portfolio Screenshots

1. **Landing Page**: Landing banner highlighting enterprise feature grid and branding.
2. **Operations Dashboard**: Central operations pulse displaying open work order counts, SLA health gauge, live operations timeline, and activity trend chart.
3. **Work Order Management**: Paginated table view displaying status pills, priority badges, technician assignments, and SLA countdowns.
4. **Work Order Details**: Deep view featuring work order timeline, assigned technician card, parts consumed line items, time tracking, and SLA status bar.
5. **Technician Portal**: Mobile-responsive technician workspace featuring "Start Work" button, timer controls, note logging, and parts logger.
6. **Customer Portal**: Customer portal displaying owned assets, active service requests, and service history.
7. **OpenAPI / Swagger UI**: Interactive API documentation interface at `http://localhost:8080/swagger-ui.html`.
